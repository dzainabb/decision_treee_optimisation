This project applies a Decision Tree Classifier to the Obesity Dataset to predict weight categories based on lifestyle and dietary habits. The dataset includes features such as caloric intake, physical activity, water consumption, and transportation methods.

Features
Preprocess dataset:
Rename columns for readability.
One‑hot encode categorical features.
Train/test split for model evaluation.
Train a Decision Tree Classifier with Gini impurity.
Visualize the decision tree flowchart.
Evaluate model accuracy before optimisation
